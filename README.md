
## v1.6.2 — النسخ الاحتياطي والاستعادة Offline
- إنشاء نسخة احتياطية لقاعدة بيانات المدرسة من داخل التطبيق عبر Android Storage Access Framework.
- استعادة النسخة الاحتياطية من أي ملف يختاره المستخدم.
- لا يحتاج النسخ أو الاستعادة إلى اتصال بالإنترنت.
- يظهر تأكيد قبل الاستعادة لأن العملية تستبدل البيانات الحالية.
