# مدرسة جعفر بن أبي طالب الأساسية — v1.6.7

نسخة تطويرية مبنية على v1.6.6 Offline Parent/Student.

## أبرز التحديثات
- بوابة الطالب وولي الأمر أصبحت تعرض نتائج الفصل الأول والثاني والنتيجة السنوية.
- الجدول يعرض أيام الدوام الخمسة: السبت، الأحد، الاثنين، الثلاثاء، الأربعاء.
- المعلم يرى طلاب صفه وشعبته فقط من شاشة الطلاب.
- المدير وحده يستطيع إضافة الطلاب.

## ملاحظة
هذه النسخة ما زالت نسخة تطويرية. يجب بناء APK عبر GitHub Actions واختباره على الهاتف قبل اعتمادها كنسخة تشغيل نهائية.
