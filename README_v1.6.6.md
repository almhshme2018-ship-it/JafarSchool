# مدرسة جعفر v1.6.6

نسخة Offline تتضمن إدارة الصف والطلاب والنتائج وملف الطالب والنسخ الاحتياطي، وتضيف بوابة محلية للطالب وولي الأمر.

## حسابات البوابة
ينشئ القائم بأعمال المدير حساباً من المستخدمين والصلاحيات، ثم يحدد أرقام الطلاب المرتبطين بالحساب. لولي الأمر يمكن إدخال أكثر من رقم مفصول بفاصلة.

## ملاحظة
البيانات الأولية داخل قاعدة البيانات تجريبية ويجب استبدالها ببيانات المدرسة الفعلية قبل الاستخدام الرسمي.
